Experiments with global, this, self, window and globalThis variables on browser

( Please open developer console to see the experiment result! )

Key points to remember:

  • All three: this, window and self points to the same object in main thread(browser) and globalThis as well except global
  • Only var attached to global object not let or const
  • in webworker, these three self, this and globalThis pointes to same object(WorkerGlobalScope) and global and window are not defined(ReferenceError)
